# 不用微信小程序的连接路线

这条路线不依赖微信小程序、不依赖 BLE 客户端。手机只需要系统 Wi-Fi 设置和浏览器。

## 设备侧行为

设备启动后会先尝试连接已保存的 Wi-Fi。若 30 秒内没有连上，会自动切到配网热点：

```text
ZecTrix...
```

屏幕首页会显示：

```text
配网热点 / ZecTrix... / 192.168.4.1
```

## iPhone 操作

1. 打开 iPhone 设置里的 Wi-Fi。
2. 连接设备热点 `ZecTrix...`。
3. 打开浏览器，访问：

   ```text
   http://192.168.4.1
   ```

4. 在页面里选择或填写 2.4GHz Wi-Fi。
5. 填会议服务地址：

   ```text
   http://10.63.7.152:8787/meeting/current
   ```

6. 提交后设备会保存 Wi-Fi，并切回 station 模式连接真实网络。
7. 设备连上后会按 `meeting/current` 拉取会议数据并刷新会议助手。

## 电脑端服务

电脑端本地会议服务保持：

```bash
python3 tools/meeting_server/meeting_server.py --host 0.0.0.0 --port 8787
```

当前示例地址：

```text
http://10.63.7.152:8787/meeting/current
```

如果电脑 IP 变化，重新用 `hostname -I` 查看，并更新配网页面的会议服务地址。

## 快速判断问题

- 看不到 `ZecTrix...`：等设备启动 30 秒，或确认设备还没有连上旧 Wi-Fi。
- 浏览器打不开 `192.168.4.1`：确认手机当前连的是设备热点，不是原来的 Wi-Fi。
- 配网后屏幕不刷新会议：确认电脑和设备在同一个网络，并且 `http://10.63.7.152:8787/health` 可访问。
