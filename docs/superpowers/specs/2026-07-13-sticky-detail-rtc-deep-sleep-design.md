# 便利贴详情页与 RTC 周期深睡设计

## 目标

在保留极趣便利贴、实验室和会议助手三层功能的前提下，完成两个用户可见能力：

1. 便利贴首页可以进入独立详情视图，长正文可以用上下键滚动，确认键切换完成状态。
2. 电池供电时由 PCF8563 每 20 秒唤醒 ESP32-S3，检查后台版本和时间状态；只有显示内容发生变化才刷新电子纸，随后重新进入深睡。

USB 或充电供电时设备保持常醒。无 Wi-Fi 凭据或配置热点开启时保持常醒，保证设备仍可配网。

## 便利贴交互

StickyNoteHomePageAdapter 内部维护 Home 和 Detail 两种视图，不新增顶层 UiPageId。

### Home

- 上下键在便签列表和最后的“实验室”入口之间移动。
- 便签被选中时，确认键进入 Detail。
- “实验室”被选中时，确认键进入实验室。
- 长按确认键仍进入实验室，保留现有快捷路径。
- 首页不再用上下键滚动正文，也不再用确认键直接切换完成。

### Detail

- 上下键按固定步长滚动正文，并限制在内容边界内。
- 短按确认键返回 ToggleComplete 动作，由板级仓库切换完成状态并回写页面。
- 长按确认键返回 Home，不进入实验室。
- 标题、完成状态、提醒时间、正文位置和滚动进度使用固定区域，任何文本不得压边或覆盖底部操作提示。

## 视觉方向

屏幕是 400 x 300 单色墨水屏。视觉语言取自“装订便签本”：左侧装订轨作为唯一识别元素，其他区域保持克制。首页负责扫描和选择，详情页负责阅读，不在同一屏同时堆叠完整正文、下一条便签和两个大入口。

首页采用 32 像素黑色标题带、左侧装订轨、主便签清单和底部实验室入口。详情页采用同一标题带和装订轨，正文使用独立裁剪视口，底部固定一行操作提示与滚动进度。

## RTC 唤醒与深睡

### 唤醒源

PCF8563 countdown timer 固定为 20 秒。ESP32-S3 使用 EXT1 ANY_LOW：

- RTC INT：GPIO5
- 确认键：GPIO0
- 下键：GPIO18

GPIO39 不属于 ESP32-S3 深睡 RTC IO，因此上键不能直接从深睡唤醒；用户可先按确认键或下键唤醒。

### 启动分类

- 冷启动或按键唤醒：完整初始化显示，保留 30 秒操作窗口。
- RTC GPIO 唤醒：保留电子纸原画面，显示刷新先暂停，联网检查预算为 12 秒。
- USB/充电：不进入深睡。

### 变化判定

RTC 保留内存记录最近已经显示的会议版本、便签版本、分钟键和提醒状态键。RTC 唤醒后只执行版本请求与时间状态计算：

- 会议版本变化：拉取会议正文并允许刷新。
- 便签版本变化：拉取便签正文并允许刷新。
- 分钟或提醒状态变化：重新渲染当前页面并允许刷新。
- 所有键均未变化：不执行物理电子纸刷新。

刷新任务恢复后必须等待显示空闲。等待超过 8 秒则本轮不睡，避免电子纸 BUSY 时切断电源。

### 睡前顺序

1. 拒绝在配置热点、无凭据、充电、网络/便签抓取或显示刷新进行中时睡眠。
2. 停止 Wi-Fi station 与 BLE 服务所依赖的活动任务。
3. 清除 PCF8563 timer flag，重新装载 20 秒 countdown。
4. 配置 EXT1 ANY_LOW 唤醒源。
5. 关闭电子纸、音频和功放电源，保持主 VBAT。
6. 调用 esp_deep_sleep_start。

## 失败与恢复

- RTC 初始化或计时器配置失败：记录错误并保持常醒。
- 12 秒内未联网或版本请求失败：保留当前电子纸画面并重新睡眠；下一周期重试。
- 显示刷新超过 8 秒：保持常醒，避免在电子纸忙时睡眠。
- 配网模式：不进入深睡。
- 任意按键活动：取消当前睡眠倒计时并重新开启 30 秒用户窗口。

## 验收

- Python UI 预览同时生成首页和详情页，检查长正文无重叠、无压边。
- 自动测试覆盖 Home/Detail 动作、板级 ToggleComplete 路由、20 秒 RTC timer、EXT1 GPIO mask、充电/配网门控、保留显示和刷新等待。
- ESP-IDF 编译通过。
- 真机串口至少观察两个完整周期：RTC 唤醒、版本不变跳过物理刷新、重新深睡。
- 修改后台版本后再观察一个周期：拉取新内容、刷新电子纸、刷新空闲后深睡。
